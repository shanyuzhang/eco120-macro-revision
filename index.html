🎯 应试策略速查

英式答题四段结构 全课程通用

① Define

用一句精确的英文定义题目中的每个术语；写出关键公式/恒等式； 明确说明模型假设（closed/open、fixed/flexible prices、short/long run）。
考官在这里给 definition marks —— 不写定义直接分析必失分。

② Diagram

几乎每道 essay 题都应该画图。必须标注：坐标轴名称、每条曲线名称、 初始均衡 E₀、新均衡 E₁、移动方向箭头。
并在正文中用文字交代图上发生了什么（"the AD curve shifts rightward from AD₀ to AD₁"）， 不能只放图让考官自己看。

③ Analyse

用 step-by-step 的因果链推导，每一步都给出机制、不能跳步：
↑G → ↑AD → ↑Y → ↑Md → ↑r → ↓I (crowding out) → 部分抵消
区分 short run vs long run、impact vs final effect、nominal vs real； 主动指出模型的假设与局限。

④ Conclude

用题目本身的措辞直接回答；说明净效应的方向与大小及其依赖的条件； 若是 Discuss/Evaluate，必须给出双方论点后再下判断。

指令动词 → 答题深度

题干动词要求
Define / State一句精确定义 + 一个例子，不需要图
Explain定义 + 机制推理，通常需要图
Show / Illustrate / Using a diagram必须有图，图是主要得分点
Analyse完整四段结构，含推理链
Discuss / Evaluate / To what extent四段结构 + 正反两面 + 有依据的判断
Compare建立对比维度表，逐维度对照，最后总结差异根源
Calculate写出公式 → 代入数字 → 带单位的答案 → 一句话解释含义

📐 全课程公式总表 考前 10 分钟

L1 国民收入核算 Ymp ≡ C + I + G + X − Z (S − I) + (NT − G) ≡ (X − Z) GDPmp = GDPbp + 间接税 − 补贴 Deflator = (Nominal/Real) × 100 GNP = GDP + NYA；NNP = GNP − 折旧
L2–L3 凯恩斯模型 C = A + cYd，S = −A + (1−c)Yd MPC + MPS ≡ 1 仅银行：k = 1/(1−c) +比例税：k = 1/[1−c(1−t)] +进口：k = 1/[1−c(1−t)+z] = 1/(s+ct+z) 平衡预算乘数 = 1 BD = G − tY；结构性：G − tY* 不可持续 ⟺ i > π + g
L4–L5 货币 H = Cash + Reserves；M = Cash + Deposits 存款乘数 = 1/rr 货币乘数 = (cp+1)/(cp+cb) M = 乘数 × H 利率 = (票息/债券价格) × 100 债券价格↑ ⟺ 利率↓ L = L(Y⁺, r⁻)，需求的是 M/P
L6–L7 IS-MP 与 AS-AD IS 向下（r↓ ⇒ I↑ ⇒ Y↑） MP 向上（Taylor rule） r − r* = a(π−π*) + b(Y−Y*) i − i* = (1+a)(π−π*) + b(Y−Y*) 挤出：垂直 MP ⇒ 完全；水平 MP ⇒ 零 Y = F(L, K, A) LAS 垂直于 Y*；SAS 向上（名义工资锁定）
L8–L9 通胀与失业 MV = PY ⇒ ΔP/P = ΔM/M（长期） r = i − π（Fisher） 通胀税 = π × (M/P) SRPC 位置由预期通胀决定；LRPC 垂直于 U* U* = 摩擦性 + 结构性（全部自愿） 均衡失业 = 在 w* 处 LF − AJ Okun：ΔY 1% ⇒ Δ就业 < 1% ⇒ Δ失业更小
L10–L12 增长·周期·贸易 ΔY/Y = ΔA/A + α(ΔK/K) + β(ΔL/L) y = Akα；稳态 sy = nk 含技术进步：y、k 以 t 增长 AK：g = sA − n 加速数：I = a[Y₋₁ − Y₋₂] 关税：收入 = T × 新进口量（转移） 净损失 = ½T·ΔQs + ½T·ΔQd

🛠️ 关于本项目 / About

这套站点是怎么造出来的

一份零依赖、零构建步骤的宏观经济学学习站点：没有任何 CDN、外部字体或框架， 27 个 HTML 文件加一份共用样式表，双击任何一页即可离线打开，在 GitHub Pages 上同样直接可用。

设计决策原因
全站内联 SVG 画图（53 张） 经济学图必须标注坐标轴、曲线名、均衡点 E₀/E₁ 与移动箭头。用手写 SVG 而非图片， 可保证任意缩放清晰、可被文本搜索、且不引入二进制资源
原生 JS，无框架 MCQ 引擎（即时判分 / 错题过滤 / 重做）与总目录关键词搜索都只需几十行； 引入框架会带来构建步骤，破坏"双击即用"
CSS 自定义属性 + 单一样式表 深色主题的色板集中定义，27 个页面共享同一套组件类（卡片 / 公式框 / 提示条 / 折叠答案）
答案默认折叠（<details>） 学习设计：强制先自测再对答案，避免"看一眼答案就以为自己会了"
讲解中文、术语与范例英文 课程为英式教学、考试用英文作答；解释用母语理解更快，但所有术语、公式与答题范例保持英文
